# Rock Paper Scissors – Python Project

## Description
A command-line Rock Paper Scissors game built using Python.  
The player competes against the computer, which makes a random choice.

## Features
- Interactive gameplay
- Random computer selection
- ASCII art for better user experience
- Input validation and result comparison

## Concepts Used
- Python lists
- Random module
- Conditional statements
- User input handling

## How to Run
1. Install Python
2. Navigate to the project folder
3. Run: python rock_paper_scissors.py
