# Password Generator – Python Project

## Description
A Python-based password generator that creates a strong, random password based on user-defined criteria such as the number of letters, symbols, and numbers.

## Features
- User-defined password length
- Random selection of letters, numbers, and symbols
- Shuffled characters for improved security
- Command-line based interaction

## Concepts Used
- Python lists
- Loops
- Random module
- String manipulation
