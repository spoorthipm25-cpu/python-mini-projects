# Treasure Island Game – Python Project

## Description
Treasure Island is a text-based adventure game built using Python.  
The player makes choices at different stages of the game, and each decision affects the final outcome.

## Features
- Interactive command-line gameplay
- Multiple decision paths
- Use of conditional statements (if-else)
- Beginner-friendly logic

## Concepts Used
- Python input/output
- Conditional statements
- String manipulation
- Game flow control

## How to Run
1. Ensure Python is installed on your system.
2. Navigate to the project folder.
3. Run the game using: python_treasure_island.py
