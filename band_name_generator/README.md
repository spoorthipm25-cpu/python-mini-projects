# Band Name Generator

The Band Name Generator is a beginner-friendly Python program that creates a fun and unique band name based on user input.  
The program asks the user for the name of the city they grew up in and the name of their pet, then combines both inputs to generate a creative band name.

## Features
- Takes user input from the command line
- Uses string concatenation to generate a band name
- Simple and easy-to-understand logic
- Ideal for beginners learning Python basics

## Technologies Used
- Python
